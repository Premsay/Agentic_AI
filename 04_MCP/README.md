## What is MCP?

**Model Context Protocol (MCP)** is an open protocol that allows AI applications to connect with external tools, data sources, and services in a standardized way.

A typical MCP architecture consists of:

```text
AI Application
     │
     ▼
   MCP Host
     │
     ▼
   MCP Client
     │
     ▼
   MCP Server
     │
     ├── Tools
     ├── Resources
     └── Prompts
```
